# Aristocrat

Creative studio site for the music world. Next.js App Router + GSAP ScrollTrigger + Tailwind.

## Run locally

```bash
cd aristocrat-site
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Brand name is **Aristocrat** only.
- Images are Unsplash placeholders — replace with your own assets in `public/` or update the URLs.
- GSAP is used for hero entrance and section fade-ups. Marquee on clients is pure GSAP.
- Extend with more project pages, real menu, or form as needed.
